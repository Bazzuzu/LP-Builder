## 1. OBJECT DEFINITION
One route fare inside a `31_OBJECT_SECTION_PRICES` table. Holds the route name, the two prices,
two detail labels, a badge, a machine-readable cabin, an airline mark and a region. Rendered as a
single `<button>` that opens the lead modal. It has no existence outside its parent's `rows`
array: it is a plain object in that array, not a stored entity with an addressable identity.

---

## 2. RELATIONSHIPS (OOUX ORCA MAPPING)

- **Belongs To (N:1):** `31_OBJECT_SECTION_PRICES`. Stored inline in `props.rows`, ordered,
  `min: 1`, `max: 30`.
- **Triggers (1:1 Event):** opens `#lead-modal`. The real payload is in §5.5 — smaller than v1's.
- **Reads (indirect):** `page.route.currency_code` for the symbol, and
  `globals.footer.legal_disclaimers` for the asterisk. Both are resolved by the parent's renderer,
  not by the row.

## 5. BUSINESS RULES & SYSTEM GUARDS (IF -> THEN)

1. **Mandatory Field Validation.** — `BUILT`
   - **IF** `row_title` or `price_value` is blank:
     - **THEN** the parent's `validate()` emits L1 `E100` against `rows.{i}.{field}`, the item is
       flagged `.invalid` in the repeater, and publishing is blocked. **Saving is not blocked** —
       L1 never blocks a draft save, so an incomplete row persists in storage (`SYS-02 §4`). v1's
       "blocks saving the row" is not what happens.

2. **Master Toggle Overrides (Parent Invariant).** — `BUILT`
   - **IF** the parent has `show_global_anchor_price === false`:
     - **THEN** `anchor_price_value` is suppressed even when this row has one. Same for
       `label_1`/`label_2` (`show_global_labels_1_2`), `label_3` (`show_global_label_3`) and the
       logo slot (`show_global_airline_logo`).
   - **Asymmetry worth knowing:** the label and price toggles are also gated on the row's value
     being non-blank, but the **logo toggle is not** — with the toggle on and no asset, the row
     renders the striped placeholder rather than collapsing the slot, so a forgotten upload stays
     visible instead of hiding.

3. **Currency & Strikethrough Rendering.** — `BUILT`, with one correction
   - **Price output:** `{currency_symbol}{price_value}`, plus a trailing `*` when the Footer's
     `legal_disclaimers` is non-empty (doc 31 §6.7).
   - **Anchor price output:** rendered as
     `<span class="prow-anchor">{symbol}{anchor_price_value}</span>`, struck through by CSS
     (`text-decoration: line-through`) at 45% opacity, followed by a 1px divider.
     **It is not a `<del>` element.** v1 specified `<del>`; the markup has never used it. The
     visual result matches; the semantics do not, and a screen reader announces no deletion.
   - Symbol comes from `page.route.currency_code` via `Intl.NumberFormat`, falling back to `$`.

4. **Regional Tab Visibility & Filtering.** — `BUILT`, with one correction
   - **IF** the parent has `region_tabs_enabled === true` and at least two distinct non-`Global`
     regions exist:
     - **THEN** this row is visible under `[All]` and under its own tab; a `Global` row is visible
       under **every** tab and contributes no tab of its own.
   - **IF** tabs are off (or suppressed for having too few regions):
     - **THEN** no filtering occurs — but `data-row-region="{region}"` is still written onto every
       row button **unconditionally**. v1 said the attribute is "completely hidden from public
       users"; it is in the published HTML either way. It is inert without a tab bar to drive it.

5. **Interactive Click → Lead Modal Dispatch.** — `PLANNED` / `DEFECT`
   - **Emitted on the row button:**
     ```html
     data-row-quote
     data-destination="{row_title}"
     data-cabin="{cabin_class}"
     data-row-region="{region}"
     aria-label="Request a quote for {row_title}, {currency}{price_value}"
     ```
   - **Forwarded into the modal by the runtime:**
     ```json
     { "destination": "this.row_title", "cabin_class": "this.cabin_class" }
     ```
   - **`PLANNED`:** `source_row_id` and `selected_row_price` are **not emitted at all**. Without
     them nothing downstream can attribute a lead to the row or to the fare that was clicked. (And
     with `row_id` itself unreliable — §4.1 — the identifier would not yet be trustworthy if it
     were emitted.)
   - **`DEFECT`:** `cabin_class` completes the journey and is dropped on arrival. The runtime
     writes it into `[data-lead-cabin]` inside the modal; the modal markup has no element with
     that attribute. A click on *"Tokyo (HND), First Class"* opens a modal where the cabin is
     neither selected nor shown. `DEFECTS.md D-05`.
   - **Accessibility:** the row is a single focusable `<button>` with the accessible name above;
     keyboard activation needs no extra handler. Nested interactive elements are absent by
     construction.

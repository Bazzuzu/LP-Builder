# Backlog — что осознанно не смоделировано

Этот файл существует, чтобы отсутствие объекта было **зафиксированным решением**, а не
незамеченной дырой. Всё перечисленное упоминается в спеках как существующее, но собственного
описания не имеет. Пока пункт здесь — на него нельзя ссылаться как на спроектированный объект.

## Несмоделированные объекты

| Объект | Кто на него ссылается | Почему нужен |
| :--- | :--- | :--- |
| `SITE_HEADER` (шапка/навигация) | 30 §4.1 — `theme_mode` переключает логотип, меню и телефон в шапке | Hero управляет чужими ассетами; объекта, которым он управляет, не существует |
| `ASSET` / медиатека | все 15 файловых полей | Нет переиспользования между страницами, лимитов веса, srcset, конвертации, `alt` как атрибута ассета |
| `PAGE_TEMPLATE` | 20 §3 «loads a template preset», реализован в `src/presets/templates.js` | Шаблоны есть в коде, контракта нет |
| `ROLE` / права | 32, 33, 34, 35 — противопоставляют Super-Admin и page editor | Read-only режимы описаны, субъекты прав — нет |
| `GlobalDomainConfig` | 20 §2 объявлен родителем страницы | Схемы нет |
| Глобальный стор Trust (Trustpilot + VIP) | 32 §2 | У Footer и Contact YAML-схема есть, у Trust — нет |

## Отсутствующие механики

- **Версионирование и превью.** Publish только меняет статус: нет превью черновика, правки
  опубликованной страницы без немедленной выкладки, отложенной публикации, отката, истории.
- **Редиректы при смене slug.** Guard ловит коллизию, но смена slug у Published-страницы молча
  ломает SEO — нужно правило автосоздания 301.
- **UTM и атрибуция.** В `telemetry` нет `utm_*`, `gclid`, `referrer`, `session_id`, `landing_url`.
- **Structured data.** Нет JSON-LD (`Offer` для таблицы тарифов, `FAQPage`, `BreadcrumbList`).
- **Локализация.** Есть `target_country`/`target_region`, нет `locale` и связи языковых версий.
- **Стратегия рендеринга.** 33 §5.3 обещает мгновенное обновление всех страниц при правке
  футера — это подразумевает SSR/ISR и инвалидацию кэша, архитектура не зафиксирована.
- **FAQ-секция.** Стандартный блок route-лендинга и прямой путь к rich snippets. Нет ни в
  спеке, ни в коде.

## Расхождения с текущей реализацией

**Единственное место в документации, где упоминается код.** Спеки описывают целевую систему;
эта таблица — разница между ней и тем, что сейчас в `src/`.

| Что | Где спека | Что в коде |
| :--- | :--- | :--- |
| Корневой объект страницы | 20 §4 — slug, status, canonical, noindex, og_image, currency, GEO | `src/store.js` хранит только `meta: {title, description}` |
| Flight Quote Modal | 21 | `src/render/page.js` — минимальный оверлей без полей формы |
| `alt` у изображений | SYS-02 §6 | Только у логотипов marquee, ни один рендерер не выводит `alt=` |
| Регионы `North America` / `Latin America` | SYS-02 §2 | Нет в `REGIONS` (`src/schema/common.js`) |
| `SECTION_FEATURE` как один параметризуемый объект | 41 §4.3 | Три типа: `primaryCards`, `secondaryCards`, `bullets` |
| Consent-чекбокс и UTM в лид-форме | 21 §3, 99 §4 | Нет |
| `cabin_class` у строки цены | 50 §4.1 | Нет |
| 301-редирект при смене slug | 20 §5.2a | Нет |
| `prefers-reduced-motion` для marquee | 40 §6.1 | Нет |
